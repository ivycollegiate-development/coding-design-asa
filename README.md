Welcome to your first repository. This repo is where you'll practice the git
workflow you'll use all semester: **pull → edit → commit → push** — and it holds
the intro exercises for our Basketball Stats App.

## Today's task

1. Open `01-hello-html/index.html` in your code-server workspace
2. Change the page to say YOUR name and YOUR favorite basketball team
3. Save, then commit and push (exact commands are below)
4. Refresh this page on github.com and look for your change

## The git cycle (memorize this)

```
git add <file>       # stage your change
git commit -m "..."  # describe your change
git push             # send it to GitHub
```

Every exercise this semester follows the same cycle. Same three commands, every time.
